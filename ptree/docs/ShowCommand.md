# Show Command

الأمر:

```text
ptree show
```

يقوم الأمر `show` بتنفيذ جميع مراحل الـ Pipeline لإنتاج شجرة المشروع.

---

## Scanner Options

تؤثر هذه الخيارات أثناء مرحلة Scanner.

| Option           | الوصف                                          |
| ---------------- | ---------------------------------------------- |
| `--from`         | تغيير مجلد بداية المسح.                        |
| `--deep`         | تحديد أقصى عمق للمسح.                          |
| `--ignore`       | إضافة أسماء ملفات أو مجلدات إلى قائمة التجاهل. |
| `--no-ignore`    | تعطيل قائمة التجاهل الافتراضية.                |
| `.gitignore`     | احترام قواعد `.gitignore` تلقائيًا.            |
| `--no-gitignore` | تعطيل استخدام `.gitignore`.                    |

---

## Processor Options

تؤثر هذه الخيارات بعد بناء الشجرة.

| Option           | الوصف                                               |
| ---------------- | --------------------------------------------------- |
| `--collapse`     | طي مجلدات محددة.                                    |
| `--collapse-all` | طي جميع المجلدات.                                   |
| `--focus`        | إظهار جزء معين من الشجرة مع فتح المسار المؤدي إليه. |

---

## Renderer Options

تؤثر هذه الخيارات أثناء تحويل الشجرة إلى نص.

| Option        | الوصف                                   |
| ------------- | --------------------------------------- |
| `--count`     | إظهار عدد الملفات لمجلدات محددة.        |
| `--count-all` | إظهار عدد الملفات لجميع المجلدات.       |
| `--no-files`  | إخفاء جميع الملفات وإظهار المجلدات فقط. |

---

## Output Options

تحدد مكان إرسال الناتج النهائي.

| Option   | الوصف                     |
| -------- | ------------------------- |
| `--log`  | حفظ الناتج في ملف.        |
| `--copy` | نسخ الناتج إلى Clipboard. |

يمكن استخدام أكثر من Output في نفس الأمر.

مثال:

```text
ptree show --copy --log tree.txt
```

سيقوم البرنامج بعرض الشجرة على الشاشة، وحفظها في الملف، ونسخها إلى Clipboard في عملية واحدة.
